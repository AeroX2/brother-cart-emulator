Brother Embroidery Card Toolkit

Check whether a .pes design will be accepted by PED-Basic, repair the one thing that usually stops it, and decode an existing card image. Everything runs in your browser — no file ever leaves this machine.

Before you flash anything.

The generator is verified to reproduce a real PED-Basic card byte‑for‑byte from that card's own contents, and the stitch data and previews are copied out of your .pes unchanged. But it has only been checked against one reference card (hoop 0, 512 KiB), and no output has yet been run on an actual sewing machine. Treat the first card you write as a test.

Check .pes files

This replays CMExeEmb::ChkPesFormat from PED-Basic 1.07 opcode by opcode, so a pass here means the real application will accept the file. Add the designs you want on one card, then build the image.

Inspect a card image

Decodes the header of an image.bin — hoop layout, the named header fields, the 3-byte pointers and the pattern attribute table.

Part of brother-cart-emulator. Format details and the reverse engineering behind them are in cardio-py/NOTES.md.
